# משימה 

* הוסיפו למחלקת השרת תבנית צופה כך ש:
1. בעת רישום והתחברות של לקוח הסרבר לפני שהוא מוסיף את הלקוח לרשימה הוא שואל אותו אם הוא רוצה להיות בשירות העדכונים (שגיאות, חדשות, עדכוני תוכנה וכו)
2. אם הלקוח מעונין ומחזיר כן אז הסרבר מוסיף אחרת ממשיך בהוספת הלקוח בצורה הרגילה.
3. שימו לב - אם הלקוח ענה תשובה שהסרבר לא ציפה לה הוא ישאל את השאלה שוב כ-3 פעמים לאחר שלושה נסיונות יוסיף את הלקוח מבלי לצרף אותו לשירות העדכונים.
